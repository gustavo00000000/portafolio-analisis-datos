# Proyecto 01: Análisis básico de ventas en Excel

## Objetivo

Analizar una base de ventas ficticia para obtener indicadores básicos y conclusiones de negocio.

## Datos utilizados

La base tendrá las siguientes columnas:

- Fecha
- Cliente
- Ciudad
- Producto
- Categoría
- Cantidad
- Precio Unitario
- Descuento
- Vendedor
- Venta Bruta
- Venta Neta

## Preguntas de análisis

1. ¿Cuál fue el total vendido?
2. ¿Cuál fue el producto más vendido?
3. ¿Cuál fue la ciudad con más ventas?
4. ¿Qué vendedor generó más ingresos?
5. ¿Qué categoría representa más ventas?
6. ¿Qué mes tuvo mejor resultado?
7. ¿Qué clientes compran más?
8. ¿Qué conclusión general se puede sacar?
