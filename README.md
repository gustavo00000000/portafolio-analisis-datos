# Portafolio de Análisis de Datos

Este repositorio documenta mi proceso de aprendizaje en análisis de datos, desde fundamentos básicos hasta proyectos integradores.

## Objetivo

Desarrollar habilidades prácticas en limpieza, análisis, visualización e interpretación de datos utilizando Excel, SQL, Power BI y Python.

## Ruta de aprendizaje

1. Excel básico y análisis descriptivo
2. Limpieza de datos
3. Dashboards en Excel
4. SQL para consultas
5. Power BI para visualización
6. Python con pandas
7. Estadística aplicada
8. Proyectos integradores
